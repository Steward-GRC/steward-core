# steward-core 🐹

> 🧭 Categories, templates, policies and procedures with versions for Steward

## 📦 Install

```bash
go get github.com/Steward-GRC/steward-core
```

## 🛠 Develop

```bash
task build    # go build ./...
task test     # go test ./...
task lint     # gofmt check + golangci-lint + yamllint
task license  # check Apache-2.0 headers (golic)
```
